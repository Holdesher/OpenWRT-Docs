# Podkop

> [!WARNING]
>
> Дополнительная информация о настройке и устранении проблем есть в документации [remote](https://docs.routerich.ru/ru/remote).

## Setup

- Перейдите в "Службы" -> "Терминал" или подключитесь по SSH `ssh root@192.168.1.1`.
- Выполните установку пакетов:

```bash
sh <(wget -O - https://raw.githubusercontent.com/itdoginfo/podkop/refs/heads/main/install.sh)
```

- После завершения скрипта продолжите настройку через терминал или повторно войдите в админку.
- Перейдите в "Службы" -> "Podkop".

## VLESS

- Перейдите в "Службы" -> "Podkop" -> "Секции":
  - Выберите `Proxy` для поля "Тип подключения".
  - Выберите `URL подключения` для поля "Тип конфигурации".
  - Укажите `vless://...` токен в поле "URL конфигурации прокси".
- Нажмите "Сохранить" и "Применить".

## AmneziaWG

- Перейдите в "Сеть" -> "Интерфейсы":
  - Нажмите "Добавить новый интерфейс".
  - Введите любое значение для "Имя".
  - Выберите `AmneziaWG VPN` для поля "Протокол".
  - Нажмите "Создать интерфейс".
  - Внизу раздела "Основные настройки" выберите пункт "Импорт конфигурации".
  - В открывшееся поле введите содержимое конфиг-файла `*.conf` и нажмите "Сохранить".
- Нажмите "Сохранить" и "Применить".
- В созданном интерфейсе должны начать меняться значения пакетов `Rx` и `Tx`.

## DNS

- Перейдите в "Службы" -> "Podkop" -> "Настройки":
  - Укажите `DNS через HTTPS (DoH)` для поля "Тип протокола DNS".
  - Укажите `9.9.9.9 (Quad9)` для поля "DNS-сервер".
  - Укажите `9.9.9.9 (Quad9 DNS)` для поля "Bootstrap DNS-сервер".
- Нажмите "Сохранить" и "Применить".

## Sections

- Перейдите в "Службы" -> "Podkop" -> "Секции":
  - Выберите нужные сервисы в "Списки сообщества".
  - Укажите нужные [allow-domains](https://github.com/itdoginfo/allow-domains) для "Список пользовательских доменов".
  - Укажите список для раздела "Исключения" (опционально).
- Нажмите "Сохранить" и "Применить".

## FAQ

- Если ранее настраивались "Сетевой интерфейс" или "Межсетевой экран", откройте "Службы" -> "Podkop" -> "Настройки" и укажите активный интерфейс в поле "Сетевой интерфейс источника".
