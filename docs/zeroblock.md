# ZeroBlock

## Setup

- Выключите `IPv6` в разделе "Мастер настройки" -> "Настройки интернета".
- Перейдите в "Система" -> "Пакеты":
  - Нажмите зеленую кнопку "Обновить список" и закройте появившееся окно кнопкой "Закрыть".
  - Введите фильтр `ZeroBlock`.
  - Внизу должны появиться два пакета: `zeroblock` и `luci-app-zeroblock`.
  - Нажмите "Установить" напротив каждого пакета по порядку. В появившемся окне нажмите "Установить" еще раз, после завершения закройте окно.
  - Введите фильтр `Amnezia`. Внизу должны появиться пакеты, нажмите "Обновить" напротив нужных пакетов (обычно 2-3 пакета). В появившемся окне нажмите "Установить", после завершения закройте окно.
- Полностью выйдите из админки через "Выйти" и войдите снова. Также рекомендуется очистить кэш браузера.
- Проверьте, что в разделе "Службы" появился "ZeroBlock".

## WG (AmneziaWG)

### Interface

- Перейдите "Сеть" -> "Интерфейсы".
- Нажмите "Добавить новый интерфейс":
  - Введите имя `AWG20`, выберите протокол `AmneziaWG VPN` и нажмите "Создать интерфейс".
- Выполните настройку интерфейса:
  - Включите параметр "Не создавать маршруты".
  - Импортируйте конфиг-файл `*.conf` через "Импорт конфигурации" -> "Загрузка конфигурации".
  - Перейдите в раздел "Настройки межсетевого экрана", введите `AWG` в поле "Пользовательский" и нажмите "Enter". Появится `AWG: (создать)`.
- Нажмите "Сохранить" и "Применить".
- Проверьте, что в интерфейсе `AWG20` меняются значения пакетов `Rx` и `Tx`.

### Section

- Перейдите "Службы" -> "ZeroBlock".
- Перейдите "Секции маршрутизации":
  - Введите `AWG2` в поле "Имя новой секции" и нажмите "Добавить секцию".
  - Укажите `VPN-интерфейс` в поле "Тип подключения".
  - Укажите `AWG20 (amneziawg)` в поле "Сетевой интерфейс".
  - Проверьте, что параметр "Отключить FakeIP" включен.
  - Проверьте, что поле "Имя секции" имеет значение `AWG2`.
- Перейдите в раздел "DNS":
  - Если нет полей для указания параметров "DNS", включите пункт `DNS через Outbound`.
  - Укажите `DNS через HTTPS (DoH)` для поля "Тип протокола DNS".
  - Укажите `9.9.9.9 (Quad9)` для поля "DNS-сервер".
  - Укажите `9.9.9.9 (Quad9 DNS)` для поля "Bootstrap DNS-сервер".
- Перейдите в раздел "Списки":
  - Выберите нужные сервисы в поле "Списки сообщества".
  - Укажите нужные [allow-domains](https://github.com/itdoginfo/allow-domains) для "Список пользовательских доменов".
  - Укажите список для раздела "Исключения" (опционально).
- Нажмите "Сохранить" и "Перезапустить".

### Screens

- Перейдите "Сеть" -> "Межсетевой экран".
- В секции "AWG" нажмите "Изменить":
  - Включите "Маскарадинг".
  - Установите "Охватываемые сети" в `AWG20`.
  - Укажите "Разрешить перенаправление из «зон источников»" в `Lan`.
  - Нажмите "Сохранить".
- В секции "WAN" нажмите "Изменить":
  - Включите "Маскарадинг".
  - Установите "Охватываемые сети" в `WAN`.
  - Укажите "Разрешить перенаправление из «зон источников»" в `Lan`.
  - Нажмите "Сохранить".
- В секции "Lan" нажмите "Изменить":
  - Выключите "Маскарадинг".
  - Установите "Охватываемые сети" только в `Lan`.
  - Укажите "Разрешить перенаправление в «зоны назначения»" в `AWG (AWG20)` и `WAN`.
  - Нажмите "Сохранить".
- Нажмите "Сохранить" и "Применить".

## VLESS

### Section

- Перейдите "Службы" -> "ZeroBlock".
- Перейдите "Секции маршрутизации":
  - Введите `VLESS` в поле "Имя новой секции" и нажмите "Добавить секцию".
  - Укажите `Сервер прокси` в поле "Тип подключения".
  - Укажите `URL прокси` в поле "Тип конфигурации прокси".
  - Укажите `vless://` ключ в "URL прокси".
  - Проверьте, что параметр "Отключить FakeIP" включен.
  - Проверьте, что поле "Имя секции" имеет значение `VLESS`.
- Перейдите в раздел "DNS":
  - Если нет полей для указания параметров "DNS", включите пункт `DNS через Outbound`.
  - Укажите `DNS через HTTPS (DoH)` для поля "Тип протокола DNS".
  - Укажите `9.9.9.9 (Quad9)` для поля "DNS-сервер".
  - Укажите `9.9.9.9 (Quad9 DNS)` для поля "Bootstrap DNS-сервер".
- Перейдите в раздел "Списки":
  - Выберите нужные сервисы в поле "Списки сообщества".
  - Укажите нужные [allow-domains](https://github.com/itdoginfo/allow-domains) для "Список пользовательских доменов".
  - Укажите список для раздела "Исключения" (опционально).
- Нажмите "Сохранить" и "Перезапустить".

## DNS

- Перейдите "Службы" -> "ZeroBlock" -> "Движок":
  - Выберите `DoH` для поля "Протокол".
  - Укажите `Quad9 (DoH/DoT)` для поля "Сервер".
  - Укажите `9.9.9.9 (Quad9 DNS)` для поля "Bootstrap".
- Нажмите "Применить" и "Перезапуск".

## Checker

> [!WARNING]
>
> После диагностики могут быть `warning` у "Zapret", "FakeIP" и прочих утилит. Это не является критической ошибкой.

- Перейдите "Службы" -> "ZeroBlock" -> "Диагностика".
- Выполните "Запустить диагностику".

## Zapret

- Перейдите в "Система" -> "Пакеты":
  - Нажмите зеленую кнопку "Обновить список" и закройте появившееся окно кнопкой "Закрыть".
  - Введите фильтр `zapret2`.
  - Внизу должны появиться два пакета: `zapret2` и `luci-app-zapret2`.
  - Нажмите "Установить"/"Обновить" напротив каждого пакета по порядку. В появившемся окне нажмите "Установить" еще раз, после завершения закройте окно.
- Полностью выйдите из админки через "Выйти" и войдите снова. Также рекомендуется очистить кэш браузера.
- Проверьте, что в разделе "Службы" появился "Zapret2".
- Перейдите "Службы" -> "ZeroBlock" -> "Авто-конфигурация":
  - Включите параметры `Установить Zapret2` и `Автозагрузка новой стратегии Zapret2`.
- Перейдите "Службы" -> "ZeroBlock" -> "Дашборд" и проверьте статус `zapret2`.

## FAQ

- Если пропало подключение или возникли иные проблемы работы "ZeroBlock":
	1. Перейдите "Службы" -> "ZeroBlock" -> "Диагностика".
	2. Нажмите "Перезапустить ZeroBlock".
	3. Дождитесь перезапуска (1–2 минуты).
