# VLAN

> [!WARNING]
>
> Эта настройка требуется, если у провайдера используется VLAN для доступа в интернет.

## Setup

- Перейдите в "Сеть" -> "Интерфейсы" -> "Устройства".
- Нажмите "Добавить конфигурацию устройства":
  - Выберите `VLAN (802.1q)` для поля "Тип подключения".
  - Выберите `Ethernet-адаптер: "eth1" (wan)` для поля "Базовое устройство".
  - Укажите `1300` для поля "VLAN ID".
  - Укажите `eth1.1300` для поля "Имя устройства".
- Нажмите "Сохранить" и "Применить".
- Перейдите в "Сеть" -> "Интерфейсы".
- Нажмите "Изменить" для интерфейса `wan`:
  - Выберите `Программное обеспечение VLAN ...` для поля "Устройство".
- Нажмите "Сохранить" и "Применить".
- Ожидаемый результат: у интерфейса `wan` появился `IPv4`, а счетчики пакетов обновляются.

## MTU

- Ethernet (IPoE/DHCP/статический IP): `1500`.
- PPPoE: `1492` или `1480`.
- PPTP: `1460`.
- L2TP: `1460` или `1400`.
- 4G/3G-модемы: `1420` или `1400`.

## FAQ

- Значения `VLAN ID` и `MTU` можно уточнить у провайдера, в настройках старого роутера или в документах о подключении.
